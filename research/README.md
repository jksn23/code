# Research artifacts

This directory keeps reproducibility material separate from application runtime code.

- `evidence/` contains versioned, reviewable evidence directories.
- `exports/` contains the latest compact CSV/XLSX/Markdown summaries.
- `releases/` contains explicitly retained sanitized archives.
- `reports/` contains generated implementation and test reports.

Runtime logs, user uploads, scratch files, credentials, and private keys are intentionally excluded from version control.
